# industrial-iac

工业数据采集端到端项目：**模拟 PLC → Python 异步采集 → MQTT → InfluxDB → Grafana**

> 湖南工业大学 · 网络工程 · 工业数据采集方向练手项目
> 周期：2026.10 - 2027.02（13 周冲刺 + 寒假打磨）

## 目标
做成一个能写进简历、面试能讲 5 分钟的端到端项目，而不是碎片脚本。

## 目标架构

```
[模拟 PLC / Modbus 从站]  (pymodbus server, 温湿度/电流寄存器)
        │  Modbus TCP  (功能码 03/04)
        ▼
[Python 异步采集器]  (asyncio + 点位配置文件 + 断线重连 + 本地缓存)
        │  MQTT  (QoS1, 主题 factory/line1/{device}/{metric})
        ▼
[EMQX / Mosquitto Broker]
        │
        ▼
[落库服务 mqtt-writer]  →  InfluxDB（时序库）
        │
        ▼
[Grafana 大屏]  （趋势曲线 / 设备在线状态 / 超温告警）
```
